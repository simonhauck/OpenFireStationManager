
# Raspberry Pi Touchscreen Setup

Configure these Raspberry Pi OS desktop settings for a touch-friendly OpenFireStationManager
display.

## Touchscreen And Desktop Settings

Configure these Raspberry Pi OS desktop settings before using the display:

- In the touchscreen monitor settings, enable multi-touch so that users can scroll with touch.
- Open File Manager, select **Edit > Preferences**, open the **General** tab, and enable
  **Open files with single click**. This lets users open desktop icons with one touch.
